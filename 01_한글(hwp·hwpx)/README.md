# 01_한글(hwp·hwpx)

한글 문서를 읽어 검토·대조할 수 있게 글자로 풀거나, 한글 COM을 안전하게 시작한다.

흐름: `hwpx_dump.py 본문.hwpx body.txt` → body.txt를 `02_보고서 검토` 도구에 넣는다.

| 파일 | 종류 | 설명 |
|---|---|---|
| `hwp_com.py` | 바로 사용 | 한글(HWP) COM 자동화 시작 도우미 — '접근 허용' 창이 매번 뜨지 않게 보안 모듈을 먼저 등록함. |
| `hwp_eq.py` | 바로 사용 | HWP(5.x) 본문에서 수식 개체(EQEDIT) 스크립트를 문단 글과 함께 순서대로 뽑음 (읽기 전용). 사용: python hwp_eq.py 파일.hwp 키워드시작 개수 |
| `hwp_tbl.py` | 바로 사용 | HWP 본문에서 키워드 뒤 첫 표의 칸 주소·병합·글자를 읽음 (읽기 전용). 사용: python hwp_tbl.py 파일.hwp 키워드 |
| `hwpx_dump.py` | 바로 사용 | hwpx 본문을 검토용 텍스트로 풀어 씀 — 문단은 한 줄씩, 표는 칸 주소(행,열)대로 격자로, 수식은 스크립트, 그림은 [그림]. 병합 칸은 첫 칸에만 글자를 두고 나머지는 빈칸. 머리말·꼬리말·각주·글상자 글자도 표시. 사용: python hwpx_dump.py 파일.hwpx 출력.txt |
