# 03_주상도(xsm)

XsiteMap 2.0 xsm(바이너리, cp949 글자)을 읽거나 고친다. 고칠 때는 사본으로 하고 원본은 백업한다.

| 파일 | 종류 | 설명 |
|---|---|---|
| `pmt_xsm.py` | 과업 예시 | 공내재하시험 결과 요약(통합).xlsx 를 통합 xsm 기준으로 맞춘다 (결과값 D·E는 손대지 않음). 결과시트 머리 칸: J4 G.W.L, G5 Geology, D7 TCR/RQD, D8 N-Value  /  요약 시트: E 지층, F N값 or TCR/RQD. 바뀐 칸에는 메모(이전 값)를 달고, 요약 시트 비고(K)에 적는다. 차트·메모가 있어 엑셀(COM)로 고친다. 사용: python pmt_xsm.py 엑셀경로 [--apply] |
| `verify_all.py` | 과업 예시 | 통합 xsm을 새로 읽어 4.2.2 정리 엑셀·공내재하 요약 엑셀의 지층·N값·TCR/RQD·지하수위를 모두 대조 (읽기만 함). |
| `xsm_size.py` | 바로 사용 | XsiteMap xsm 파일에서 시추공별 시추 규격(BX/NX 등)을 뽑음. xsm은 바이너리지만 공번(No.000(A) 꼴)과 규격 글자(BX·NX·HX·PX)가 cp949로 그대로 들어 있어, 규격 글자 앞에서 가장 가까운 공번을 짝지음. 공번 모양이 다른 과업이면 --hole 정규식을 바꿔서 씀. |
| `xsm_uscs_fix.py` | 과업 예시 | 실내시험 결과(SM)로 붕적층 3개 지층 고치기: No.359(B)·381(C)·382(D) 분류 'GM:실트질 자갈'→'SM', 지층모양 'GM'→'SM', 지층구성·설명 첫 줄 '모래섞인 실트질 자갈'→'자갈섞인 실트질 모래' (xsm에 이미 있는 표기). 설명 2번째 줄 이후·심도·색상·SPT·코어는 그대로. 다른 지층은 손대지 않음(전·후 파싱 비교). 사용: python xsm_uscs_fix.py 입력.xsm 출력.xsm |
| `xsmparse.py` | 바로 사용 | XsiteMap 2.0 통합 xsm에서 공별 지층·SPT·코어 기록을 직접 추출. |
