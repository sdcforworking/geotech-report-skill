# XsiteMap 주상도(xsm) 편집 규칙 — 참고

2026-10 동해안~신가평 10공구 때 사용자가 정한 규칙. 다른 과업에서는 **사용자에게 같은 규칙을 쓸지 먼저 묻는다.**
편집은 바이트(TLV) 단위로 했고, 단계마다 사용자가 XsiteMap에서 열어 확인했다.

## 일반정보
- 위치의 X·Y를 시추위치 X/Y에 복사. 위치 형식 `X=553,248.533, Y=280,738.253`(천 단위 쉼표).
- 발주처 = 한국전력공사(그 과업 기준).
- 비트: 공내재하시험을 한 공 = NX, 나머지 = BX.
- 케이싱 심도 = 풍화암 바닥(풍화암이 없으면 기반암 바로 위 심도).
- 주상도 양식(출력 틀)은 과업에서 정한 하나로 통일(그때는 `한전 전기공급시설(수정용)`).

## 지층
- 지층 이름과 색인이 맞아야 함: 풍화토 / 풍화암 / 연암 ('연암층' 아님). 지층모양: 풍화암 WR, 연암 SR.
- 암종 이름: 화강편마암 → 화강암질 편마암, 쉼표 뒤 한 칸("화강암, 편마암"). 연암 공의 암종은 xsm 이름 그대로 둔다(화강암질 편마암을 바꾸지 말 것 — 한 번 고쳐져서 사용자가 바로잡음).
- 풍화암에서 끝난 공의 암종은 지질도에서: 흑운모 화강암·석영반암 → 화강암, 호상 흑운모 편마암·규장질 편마암 → 편마암. 암 구분은 화강암/편마암(화성암/변성암 아님).
- 지층구성 = 지층설명 첫 줄. 지층 색상 칸 = 지층설명의 색상 줄.
- 통일분류(지층구성 기준): 모래섞인 자갈 → GP, 모래섞인 실트질 자갈 → GM, 자갈섞인 실트질 모래 → SM.
- 실내시험 USCS가 다르면 실내시험을 따라 xsm을 고친다(풍화암은 WR 유지).

## 지층설명
- "(0.0~1.5m)" 같은 구간 머리와 빈 줄을 지우고, 줄마다 "-"로 시작.
- 표현: 풍화암편 → 암편(협재 꼴), "대상 길이 내외 회수", "기호(재료) 크기 충진".
- TCR/RQD 줄은 지운다.
- 풍화암까지의 순서: 구성성분, 색상, (함수상태), N값 용어, 기타. 줄 사이 빈 줄 없음.
- 풍화암 둘째 줄: "-굴진 및 표준관입시험 타격 시 암편섞인 실트질 모래로 분해".
- 연암: 구성성분, 색상, D, S, F 각 한 줄 → 굴진 구간마다 `#a~bm`, `-nSet+Random set`, ` (각도˚)`, `-파동형/거침`, 충전·변색 줄(구간 사이 빈 줄). DSF 글자는 나쁜 쪽부터(약함~강함), 코어 표 숫자는 작은 쪽부터(3~4).
- 함수상태: 풍화암은 빼고, 지하수위가 시추심도 아래면 모든 지층에서 뺀다.
- N값 상대밀도 용어는 SPT N으로 계산(범위가 겹치지 않게). SPT가 없는 지층은 용어 없음.
- 풍화토/풍화암 경계 = 관입량 10cm 이하(50/10)가 처음 나오는 SPT.
- 풍화암-연암-풍화암이 짧게 반복되면 보수적으로 한 풍화암으로 합치고 가운데를 "암편 협재"로 쓴다.

## 단면도(xsm 안)
- 단면도 노드는 프로젝트 바로 아래, 주상도들 뒤(폴더 없이). 사용자가 준 예시 파일의 XsiteMap2.0 기록을 복사해 이름만 바꿈. `.xss`는 만들지 않음.
- 배치: 1공 철탑 → 단면 1개, 2공 → 1개, 4공 → 둘레 4개(A–B, D–C, B–C, A–D).

## 충돌
- 사용자가 XsiteMap을 열어 둔 채 저장하므로, 덮어쓰기 전 해시를 비교하고 바뀌었으면 사용자 판을 기준으로 다시 한다.
