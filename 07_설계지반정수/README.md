# 07_설계지반정수

'암종별 N값 모음' 엑셀을 단계별로 만든 도구(사용자가 값을 정하고, 계산은 엑셀 함수로). 순서:

1. `rock_n.py` 암종별 N값 시트 → 2. `rock_n_stat.py`·`rock_n_orig.py` 범위·평균(환산/원래 형식) → 3. `rock_n_rep.py` 대표 N값(방법별 평균, 적용 방법 선택) → 4. `rock_n_phi.py` 내부마찰각 → 5. `rock_n_coef.py` 경험식 계수 → 6. `rock_n_e.py` 변형계수 → 7. `case_vert.py` 기존 설계사례(본문 배치) → 8. `lit_sheet.py`·`lit_e.py` 관련 문헌자료 → 9. `lit_range.py` 문헌 범위 정리(후보 O/X) → 10. `result_sheet.py` 산정결과 정리(본문 표 형식) → 11. `ev_apply.py` 변형계수·포아송비 적용값

시트끼리 칸을 참조하므로, 다 만든 뒤에는 시트를 지우고 다시 만들지 말고 칸만 고친다.

| 파일 | 종류 | 설명 |
|---|---|---|
| `case_vert.py` | 과업 예시 | '기존 설계사례 요약' 시트를 본문 5.2 표와 같은 배치로 다시 만듦 — 암종별로 행 = 정수(단위중량·점착력·내부마찰각), 열 = 표토/붕적층 모래·자갈, 풍화토. 값은 사용자가 준 본문 표 그대로. 아래에 같은 배치로 비교용 최소·최대 숫자 표. 병합 없음, 탭 하나만 선택. 사용: python case_vert.py 파일.xlsx |
| `ev_apply.py` | 과업 예시 | '산정결과 정리' 시트: 변형계수 · 포아송비 적용 설계정수(사용자 확정값)를 노란 칸에 넣고, 선정사유 자리표시 줄을 사용자 확정 문구로 바꿈(줄 끼워 넣기). 시트는 지우지 않음. 사용: python ev_apply.py 파일.xlsx |
| `lit_e.py` | 과업 예시 | '관련 문헌자료' 시트 맨 아래에 변형계수 · 포아송비 문헌 표 4개 추가 (본문 ④ 변형계수 및 포아송비 산정의 문헌자료 검토 값 그대로). 본문 표에서 합쳐진 칸(Das 자갈 E·ν, Bowles 자갈·점토 ν, Hunt ν)은 hwp 표 구조를 읽어 칸마다 채움. 위쪽 표 칸 위치는 그대로(다른 시트가 참조). 사용: python lit_e.py 파일.xlsx |
| `lit_range.py` | 과업 예시 | '문헌 범위 정리' 시트 — 본문 '구간별 단위중량 및 강도정수 산정결과' 표의 '관련 문헌자료' 칸에 넣을 범위를 정리. 아래 후보 목록: 지층마다 해당하는 문헌 항목(통일분류 · 대표 N값 상대밀도로 고름)을 '관련 문헌자료' 시트 칸에서 함수로 끌어오고, 사용(O/X)을 고름. 위 요약: 본문 표 배치(행 = 지층 · 정수)로, 사용 O인 항목의 최소∼최대와 근거를 함수로 보여 줌. 엑셀(COM)로 작성, 병합 없음, 탭 하나만 선택. 사용: python lit_range.py 파일.xlsx |
| `lit_sheet.py` | 과업 예시 | 암종별 N값 모음 엑셀에 '관련 문헌자료' 시트 추가 — 사용자가 준 본문 '문헌자료 검토' 표 4개(도로설계요령 2009 · 철도설계기준 2011 · 서울시 지반분류 2006 · Hunt 1987)를 값 그대로. 병합 없이 원문에서 합쳐진 칸(종류·통일분류·재료명)은 줄마다 채움. 철도설계기준 점성토 단위중량은 원문 표에서 상태 구간이 합쳐져 있어 어느 상태에 해당하는지 붙여넣기만으로는 알 수 없음 → 원문 순서대로 따로 적음. 사용: python lit_sheet.py 파일.xlsx |
| `result_sheet.py` | 과업 예시 | '산정결과 정리' 시트 — 본문 '구간별 단위중량 및 강도정수 산정결과' 표 형식(행 = 지층 · 정수, 열 = 관련 문헌자료 · 경험식(평균) · 기존 설계사례 · 현장/실내시험 · 적용 설계정수)으로 다섯 정수를 모음. 앞 네 칸은 다른 시트와 함수로 연결, 적용 설계정수(노란 칸)는 사용자가 정한 값(강도정수)을 넣고 변형계수 · 포아송비는 비움. 사용: python result_sheet.py 파일.xlsx |
| `rock_n.py` | 과업 예시 | 4.2.2 정리 엑셀 '암종별 N값 자료'(720회)를 암 구분(화강암/편마암)별 시트 두 개로 나눠 새 엑셀로 만듦. 지층 순서(붕적층 모래→자갈→풍화토 N≤30→N＞30→풍화암) → 공번(보고서 순서) → 심도 순. 30cm 환산 N값은 엑셀 수식. 사용: python rock_n.py 출력.xlsx |
| `rock_n_coef.py` | 과업 예시 | 암종별 N값 모음 엑셀에 '경험식 계수' 시트 추가 (옛 'N값 정리_수정.xls'의 '지층별 적용 계수' 표 방식). 지층별 Dunham 상수 · Schmertmann α · Bowles 흙 종류를 한곳에 두고, 'N값 내부마찰각' 시트 Dunham 상수(F열)는 여기서 끌어옴. 아래에 계수 고르는 기준표(Dunham · Schmertmann · Bowles · Hisatake · 도로교 · 점착력 식)도 정리. 사용: python rock_n_coef.py 입력.xlsx 출력.xlsx |
| `rock_n_e.py` | 과업 예시 | 암종별 N값 모음 엑셀에 'N값 변형계수' 시트 추가 — 대표 N(대표 N값 시트 S열)과 계수('경험식 계수' 시트 α·Bowles 흙 종류)로 보고서 5.3.1 표와 같은 5개 식(Schmertmann · 구조물기초(Bowles) · Hisatake · 도로교 · 한국지반공학회) 계산. 평균은 보고서처럼 최대값 제외. 사용: python rock_n_e.py 입력.xlsx 출력.xlsx |
| `rock_n_orig.py` | 과업 예시 | 암종별 N값 모음 엑셀: 지층별 표에 원래 형식(회/cm) 최소·최대·범위·평균 열(W:Z)을 수식으로 추가. 최소·최대 = 환산 N 최소·최대가 나온 시험의 N값 표기(J열). 평균 = 환산 평균이 50 이하면 반올림/30, 넘으면 50/(1500÷평균 반올림). 사용: python rock_n_orig.py 입력.xlsx 출력.xlsx |
| `rock_n_phi.py` | 과업 예시 | 암종별 N값 모음 엑셀: 1) '대표 N값' 시트에서 사용자가 노란색(FFFF00)으로 칠한 방법 칸(L~O)을 읽어 Q열(적용 방법)에 그 방법 이름을 넣음 → S열 대표 N 계산. 2) 'N값 내부마찰각' 시트 추가 — 대표 N(S열)을 끌어와 보고서 5.3.1과 같은 4개 경험식(도로교·Dunham·Peck·Ohsaki)으로 φ 계산. 사용: python rock_n_phi.py 입력.xlsx 출력.xlsx |
| `rock_n_rep.py` | 과업 예시 | 암종별 N값 모음 엑셀에 '대표 N값' 시트 추가 — 토사층(붕적층·풍화토) 지층별로 여러 방법의 평균을 함수로 계산하고, 노란 칸(적용 방법·직접 입력·판단 근거)을 고르면 대표 N값(회/cm)·상대밀도가 나옴. 관입불능 = 타격수 50회 · 관입량 30cm 미만. 사용: python rock_n_rep.py 입력.xlsx 출력.xlsx [시험용: 방법들을 채움] |
| `rock_n_stat.py` | 과업 예시 | 암종별 N값 모음 엑셀: 오른쪽 지층별 표(P:R)에 30cm 환산 N값 최소·최대·범위·평균 열을 수식으로 추가. 사용: python rock_n_stat.py 입력.xlsx 출력.xlsx |
