# 04_엑셀

엑셀을 COM으로 고칠 때의 틀과 보조 도구. 규칙은 상위 README의 '엑셀' 요령 참고(탭 하나 선택, DispatchEx, 병합 칸 금지).

`excel_com_edit_example.py`는 "바꾸기 전 값이 예상과 같은지 확인 → 바꾸기 → 탭 하나 선택 → 저장" 틀이다. 칸 주소와 값을 바꿔서 쓴다.

| 파일 | 종류 | 설명 |
|---|---|---|
| `excel_com_edit_example.py` | 과업 예시 | '산정결과 정리' 풍화토(N＞30) 변형계수 적용값을 사용자가 정한 값(화강암 80, 편마암 60)으로 바꾸고 [변형계수 및 포아송비] 선정사유의 풍화토(N＞30) 줄을 본문에 넣을 문장으로 바꿈. 바꾸기 전 값이 예상과 다르면 멈춤. 사용: python e_n30_apply.py 파일.xlsx |
| `lab_uscs.py` | 과업 예시 | 보고서 46회 시험의 원본 USCS 시트(Classification of a Soil)를 보고서 순서대로 한 엑셀에 모음. 원본 xls → 임시 xlsx(깨진 이름 정의 삭제) → 시트 복사 → 원본 연결 끊어 값·차트 고정 → 원본과 값·입도곡선 점 대조. 사용: python lab_uscs.py 출력.xlsx |
| `log_move.py` | 바로 사용 | 폴더 정리 이동 내역 엑셀에 한 줄 추가 (원래 위치 / 새 위치 / 비고). 기록 파일은 --log 또는 환경변수 MOVE_LOG로 지정. 엑셀이 열려 있으면(~$ 잠금 파일) 멈춤. 기록 시트 이름은 '이동 내역'(없으면 첫 시트). |
| `tabcolor.py` | 과업 예시 | (설명 없음 — 코드 참고) |
| `xl_live.py` | 과업 예시 | 열려 있는 엑셀 통합문서들의 '암종 구분' 시트 값을 읽기만 한다 (저장·수정 없음). |
| `xl_pdf.py` | 바로 사용 | (설명 없음 — 코드 참고) |
