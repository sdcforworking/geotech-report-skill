# 06_단면도·삽도

이번 과업에서 지층단면도(철탑별 ai·jpg·dxf)와 N값-심도 그래프를 만들고 한글 그림 칸에 넣은 도구. 자료 경로·칸 크기·철탑 목록이 박혀 있어 새 과업에서는 위쪽 상수를 바꿔서 쓴다.

| 파일 | 종류 | 설명 |
|---|---|---|
| `lockfig.py` | 과업 예시 | 종단면도 그림칸 표: 크기 고정만 켠다 (칸·내용은 손대지 않음). |
| `nfig.py` | 과업 예시 | n값.ai 양식으로 암종별(화성암·변성암) N값-심도 삽도 4장(붕적층, 풍화대)을 만든다. ai(PDF 호환) + jpg(300dpi). 점 자료: 4.2.2 시추조사결과 엑셀 '암종별 N값 자료' 시트. 사용: python nfig.py 엑셀경로 출력폴더 [폭mm 높이mm]   (기본 79 × 38mm; 양식 n값.ai 는 53 × 41mm) 글자·마커·범례 크기와 그래프 틀 바깥 여백은 양식 그대로 두고, 그래프 틀만 용지 크기에 맞춰 늘이거나 줄인다. |
| `putfig.py` | 과업 예시 | 그림칸 표에 칸맞춤 단면도 jpg 넣기. 4공 구간은 위 표 A-B, A-D / 아래 표 B-C, D-C (기존 배치 순서). 사용: python putfig.py 입력.hwp 출력.hwp [철탑 ...] |
| `section_ai.py` | 과업 예시 | 지층단면도 PDF(.ai 호환)/JPG 생성 — 참고 ai(지층단면도260626(273~280).ai, 274-A 쪽)에서 실측한 양식 사용. |
| `section_dxf.py` | 과업 예시 | 지층단면도 DXF 생성 (참고: 종단면도 삽도 참고자료 / 지층단면도_No.1(273)-A.jpg 양식). |
| `vectorcraft_layers.py` | 바로 사용 | VectorCraft로 지층단면도 ai(한 레이어에 객체가 섞인 것)를 공번·지층명·프로파일·시추주상·거리값·표고축·지반고·지층선·지층(색) 레이어로 나눠 사본 폴더에 저장하고, 파일마다 정리 전후 그림 픽셀·객체 수를 비교해 `_report.json`에 남김. 분류는 글자 내용·색·위치(시추 기둥 기준)로 함. 사용: python vectorcraft_layers.py 원본ai폴더 출력폴더 |
| `section_fit.py` | 과업 예시 | 보고서 그림칸 크기에 맞춘 지층단면도 (section_ai 양식 그대로, 용지를 칸 크기로 잡고 배치·세로축척만 맞춤). 사용: python section_fit.py 출력폴더 [단면이름 ...] |
